`000003_launch_sports/001_sports.sql` uses SPORT_CODE as its MERGE key, inserts unmatched records only, and leaves existing names/labels/order/active flags untouched. Numeric sport IDs are generated by identity and are never hardcoded or guessed. New rows start active; later reviewed admin functionality owns customization. Repeating the seed must preserve existing rows and create no duplicates; SQL inspection is not a real Oracle rerun test. The seed and its APPLIED transition commit together after postconditions, while its pre-work RUNNING marker is retained separately for failure tracking.

OTHER remains unseeded. There are no themes, plans/prices, tenants, business/customer/staff records, default passwords or administrator accounts in deployment seeds. Test fixtures are separate from seeds.
