## Proposed additions

| Table                            | Ownership    | Need / approval gate                                                                                                                               |
| -------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `INVITATION_LOCATIONS`           | Tenant-owned | Persist authorized pending branch assignments until invitation acceptance (Q-17). Proposed; not yet approved.                                      |
| `SUBSCRIPTION_FEATURE_SNAPSHOTS` | Tenant-owned | Immutable entitlement limits copied at assignment/renewal; plan edits must not rewrite historical entitlements (Q-10). Proposed; not yet approved. |

The migration plan creates only included tables plus reviewed additions. Original uploads remain an immutable reference; no existing implemented table is dropped. PLATFORM_SETTINGS is only a controlled non-secret key allowlist, not a generic business-data store. RESOURCE_FEATURES represents optional display attributes, never pricing/capacity/authorization logic. NOTIFICATION_TEMPLATES is global-only/email-only for MVP; tenant-custom templates and all other channels remain dormant. WEBSITE_SETTINGS.SUBDOMAIN_SLUG handles platform host routing; DOMAINS/DOMAIN_VERIFICATIONS are not required for it. Global USERS are staff/owner identities; CUSTOMERS.USER_ID remains dormant/null in guest MVP and does not add customer accounts.

Table inclusion is a recommendation derived from MVP scope; unresolved policy/amendment details remain in the [decision register](../planning/decision-register.md#step-05-design-review). No proposal is made an approved product policy by this matrix.
